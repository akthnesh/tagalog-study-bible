# Tagalog Study Bible UI v0.3

UI milestone based on the supplied dark three-pane reference.

- Desktop three-pane shell
- Dark scholarly visual language
- Gold accent
- Left Old/New Testament navigation
- Central Scripture reader

- Context-sensitive study panel
- Study / Exegesis / Theology / References tabs
- Search-bar foundation
- Responsive mobile bottom controls

Prototype Bible text is sample content only. Production ABTAG2001 data will be connected after the visual shell is accepted.
